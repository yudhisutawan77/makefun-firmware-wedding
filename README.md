One funny, heartfelt wedding vow spoken by a robot at its own wedding — a
single sentence, under 200 characters.

> I vow my sensors will always find you first in a crowded room, my battery will only ever die beside yours, and no firmware update will ever overwrite us.

[View the bounty on make.fun](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929)

`main.py` (Python, stdlib only) writes the vow to `$ENTRY_OUT`, whether that
is a file path or a directory.
